    SDK 概览¶

    English

    产品简介¶

    North SDK 是 Sharpa North 机器人的软件开发套件，提供 C++ 和 Python 接口。开发者可以通过各个 Client 获取机器人状态、调用设备服务，以及发送关节位置和底盘速度命令。

    C++ 接口位于 north 命名空间，公共头文件为 <north_sdk/NorthSDK.h>。Python 包名为 north_sdk。两种语言使用相同的功能模型；返回值和资源管理方式遵循各自语言的习惯。

    图中列出 C++ 的访问器写法；Side 按机器人自身左右侧选择。Python 使用 Side.LEFT / Side.RIGHT。

    NorthSDK 是统一入口，各 Client 由对应访问器直接获取。MasterClient 管理整机状态与任务，部位 Client 控制相应机构，WholeBodyClient 组合多个部位的命令；其余 Client 提供传感、视频、时间对齐、电源和配置能力。图中按用途分组。

    功能模块¶

    模块 用途
    Master 运行状态、健康、任务事件及系统管理服务
    WholeBody 组合多个部位的关节位置目标与底盘速度命令
    Chassis 状态、速度命令、模式切换、使能与复位
    Torso 躯干与颈部的 8 关节状态、位置命令及服务
    Arm 左右臂的 7 关节状态、位置命令及服务
    Hand 左右手的 22 关节状态、位置命令、触觉及服务
    Sensors IMU、超声、电子皮肤与 Lidar
    Power 电源板、电池状态与电源管理服务
    Video 头部双目 H.265、双腕 H.264 视频解码与 JPEG 回调；推荐 NVIDIA NVDEC，软件解码作为兼容选项
    Alignment 按源时间戳匹配视频、设备状态和 Master 状态
    Config 发现并安全修改机器人开放的持久化用户配置

    实际可用功能取决于机器人的设备配置及软件版本。接口详情见 软件服务接口.

    接口交互方式¶

    方式 典型接口 含义
    订阅 on_*() 持续接收状态或事件，保存并管理订阅句柄
    缓存读取 latest_*(max_age) 读取本地最近样本，检查数据新鲜度
    命令发送 send_*() 提交命令；提交成功后仍需观察设备反馈
    服务调用 set_mode() / reset() 等待响应，同时检查 SDK 错误和业务结果

    使用环境¶

    项目 要求
    运行系统 推荐 Ubuntu 22.04 LTS x86_64 / Ubuntu 24.04 LTS x86_64
    C++ 接口 C++17，使用交付包中的公共头文件和库
    Python 接口 推荐 CPython 3.10.x / 3.12.x；解释器次版本及架构须与包内实际提供的绑定匹配，具体以安装包清单为准
    机器人 配套软件、可访问的通信地址及所需设备
    视频组件 安装包统一包含视频能力、GStreamer 运行库和所需插件；默认硬解要求支持 H.264/H.265 解码的 NVIDIA 独显及匹配驱动。

    实际可用能力以交付包、运行依赖和机器人配置为准。C++ 头文件、Python 扩展和 SDK 动态库应来自同一交付包；配套机器人软件版本以交付说明为准。

    SDK 默认启用时间同步。首次使用需完成主机准备；默认软件模式会调整开发机系统时间，详见时间同步。

    阅读路径¶

    1. 应用开发：从“快速开始”完成只读连接验收，再了解资源管理、服务结果和运动准入。
    2. 例程参考：按任务选取 C++ 或 Python 示例。
    3. 软件服务接口：查询支持状态、参数、返回类型、单位和数据字段。
