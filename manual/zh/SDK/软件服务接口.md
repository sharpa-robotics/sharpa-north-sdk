## 接口阅读约定

本章覆盖 SDK 对外的订阅、缓存、Action 和同步 Service。类位于 `north` 命名空间。下面列出接口声明及公共数据类型；C++ 应用使用 `<north_sdk/NorthSDK.h>`。

## 通用参数与结果

| 对象 | 使用规则 |
| --- | --- |
| `Status` | connect 和 Action 的 SDK 结果，通过 ok()/bool 检查 |
| `Result<T>` | 先判断 bool，再读 value；失败读 error.code/message |
| `BasicResponse` | 在 Result 成功后继续检查 success 和 message |
| `MasterResponse` | 检查 result 是否 kOk；before/after 是服务快照 |
| `Header` | `stamp_ns` 为数据源时间，`system_time_ns` 为远端系统时间；时间域可能不同。`seq` 为序号，`key` 标识来源，`frame_id` 为来源或坐标系标识。 |
| `Side` | kLeft/kRight；Python LEFT/RIGHT；非法值拒绝 |

默认使用 SI 单位：m、rad、m/s、rad/s、N、Nm、A、V；温度 °C。时间字段按 `_ns/_ms/_s`，电源时钟域按显式 clock_domain 判断。数组按固定设备关节顺序；四元数字段顺序为 w/x/y/z。

以下规则适用于使用 `SubscribeOptions` 的状态/事件订阅，以及 `latest_*` 缓存读取；VideoClient 和 AlignmentClient 的专有选项见各自说明。

| 通用参数 | 类型、默认值与规则 |
| --- | --- |
| `callback` | C++ `std::function<void(const T&)>`，Python callable，必填且非空；C++ 引用仅在回调内有效，需要长期使用的数据应复制。 |
| `options` | `SubscribeOptions`，默认 DropOldest；设置本地回调排队策略。Python 默认 `SubscribeOptions()`。 |
| `max_age` / `max_age_ms` | C++ milliseconds 必填；Python int 默认 1000 ms。必须非负，按 SDK 本机接收样本后的时长判断，与消息中的时间戳无关。 |

`on_*` 返回订阅句柄，必须保存；句柄析构、`close()` 或退出 Python 订阅上下文会取消订阅。回调由 SDK 工作线程执行，应保持短小；`close()` 返回后不再开始新回调。

`latest_*` 自动接收状态并返回缓存副本，无需预先订阅。尚无样本或超过最大年龄时为 `kStaleState`，负数年龄为 `kInvalidArgument`。按设备发布周期和应用时效设置最大年龄。C++ 检查 `Result<T>`；Python 直接返回数据或抛 `NorthSDKError`。

## 错误与结果检查

一次调用的错误、机器人服务的业务结果和运行中的设备故障应分别检查：

| 层次 | 获取方式 | 处理 |
| --- | --- | --- |
| SDK 调用结果 | C++：`Result<T>.error().code/message` 或 `Status.code()/message()`；Python：捕获 `NorthSDKError`，读取 `.code` 和异常文本 | 先处理参数、连接、超时或 SDK 运动门禁等调用问题。错误码见下表。 |
| 机器人服务结果 | 普通响应的 `success/message`；Master 的 `result/message`；配置服务的 `result` 和 `diagnostics` | 收到响应后仍需判断业务是否成功。Master 检查 `MasterResult::kOk`，配置服务检查 `ConfigResult::kOk`。 |
| 机器人运行故障 | 对应 Client 的 `on_heartbeat()`：`error_code/fault_mask/fault_codes`；Master 的 `on_error()` / `on_degradation()`：`error_code/reason/device_errors` | 停止发送运动目标，记录部位、故障码和 reason；排除现场原因后再复位，持续故障联系技术支持。 |

设备故障码按对应设备解释：`HandServiceResponse.sdk_error_code` 来自手部设备 SDK，`PowerCommandResponse.error_code` 来自电源服务。North SDK 调用错误使用 `ErrorCode`；`kRemoteFailure` 表示收到通信错误回复。

| ErrorCode | 处理 |
| --- | --- |
| `kOk` | 成功 |
| `kInvalidArgument` | 修正长度、有限值、枚举、确认参数或配置 |
| `kNotConnected` | 连接成功后再调用 |
| `kUnavailable` | 检查设备服务可用性与连接 |
| `kTimeout` | 等待响应超时；有副作用时先确认结果 |
| `kSerialization` | 核对配套软件版本，保留错误信息与日志 |
| `kTransport` | 保留 Zenoh/网络错误并检查连接 |
| `kStaleState` | 缺失、损坏或过期；等待新鲜状态 |
| `kOutcomeUnknown` | Master 操作结果未知，核对状态，不自动重试 |
| `kRemoteFailure` | 收到 Zenoh 错误回复，查看 message |
| `kInternal` | 保留错误信息与日志，联系技术支持 |
| `kMotionNotAllowed` | 检查 Master 阶段和通道/mode |
| `kNotSupported` | 当前版本或设备不支持所请求的操作或参数；检查调用参数和版本适用范围 |
| `kTimeSyncUnavailable` | 检查主机组件是否已安装及服务错误信息。 |
| `kTimeSyncPermission` | 使用获授权账号；软件模式还需允许调整系统时间。 |
| `kTimeSyncUnsupported` | 检查所选模式和网卡时间戳能力。 |
| `kTimeSyncConflict` | 检查其他授时进程或不同配置的对时会话。 |
| `kTimeSyncTimeout` | 检查链路和网卡，确认对时是否继续收敛。 |
| `kTimeSyncLost` | 同步未就绪或已失效，等待重新就绪。 |

调用超时或收到错误回复后，服务端操作可能已经执行。重试前先确认实际状态。

## Python 对应关系

| C++ | Python |
| --- | --- |
| `NorthSDK::Create(config)` + `connect()` | `NorthSDK(config)` + `connect()` / `with NorthSDK(config)` |
| `Result<T>` | 直接返回 T；SDK 错误抛 NorthSDKError |
| `Status` | 成功返回 None；失败抛 NorthSDKError |
| `Side::kLeft` / `CommandChannel::kTeleoperation` | `Side.LEFT` / `CommandChannel.TELEOPERATION` |
| `connect_timeout` / `master_status_max_age` | `connect_timeout_ms` / `master_status_max_age_ms` |
| `latest_state(std::chrono::milliseconds(200))` | `latest_state(200)` |
| `sdk->connected()` / `subscription.active()` | `sdk.connected` / `subscription.active` |
| `std::optional<T>` | 值或 None |
| `std::array / std::vector` | Python 序列 |
| 二进制 std::string 字段 | `bytes` |

Python 参数类型或长度不匹配时，也可能抛出 `TypeError`。

### Python 常用签名

除下表所列差异外，方法名与 C++ 相同，枚举采用大写下划线。订阅方法的 `options` 可省略，默认为 `SubscribeOptions()`；同步服务直接返回响应对象。

| Python 调用 | 返回 |
| --- | --- |
| `NorthSDK(config)`；`sdk.connect()`；`sdk.close()` | SDK 对象；后两者成功返回 `None`。 |
| `sdk.time_sync_diagnostics()`；`sdk.robot_time_ns()` | `TimeSyncDiagnostics`；纳秒整数。 |
| `client.latest_state(max_age_ms=1000)` | 对应部位状态；`latest_status/latest_imu/latest_battery` 也使用 `max_age_ms=1000`。 |
| `client.on_state(callback, options=SubscribeOptions())` | `Subscription`；Master 使用 `on_status`。 |
| `sdk.master().on_heartbeat(subsystem, callback, options=SubscribeOptions())` | `Subscription`。 |
| `sdk.master().set_mode(mode)`；`start_task(task_id)`；`stop_task(status=0)` | `MasterResponse`，检查 `result`。 |
| `sdk.arm(side).send_joint_positions(positions)` | `None`；`positions` 长度为 7，手部同名方法长度为 22。 |
| `sdk.torso().send_joint_command(command)` | `None`；`command` 为 `JointCommand`。 |
| `sdk.whole_body().send(channel, command)` | `None`；`command` 为 `WholeBodyCommand`。 |
| `sdk.video().on_jpeg(source, callback, options=VideoOptions())` | `Subscription`；`diagnostics(source)` 返回 `VideoDiagnostics`。 |
| `sdk.alignment().on_frame(options, callback, callback_options=SubscribeOptions())` | `Subscription`；`diagnostics(subscription)` 返回 `AlignmentDiagnostics`。 |
| `sdk.config().get(plugin_id="")`；`set(plugin_id, operations)` | `ConfigGetResponse` / `ConfigSetResponse`。 |

Python 容差使用整数 ns（`max_skew_ns`），等待和缓存年龄使用整数 ms（如 `timeout_ms`、`wait_timeout_ms`）。`sdk.connected`、`subscription.active`、`sample.matched` 是属性，不加括号。

## 公开能力范围

各 Client 提供的能力如下。

| Client | 公开能力 |
| --- | --- |
| Config | 配置实例发现、字段描述、持久化 SET/RESET |
| Master | 状态、硬件健康、事件、心跳、任务和系统生命周期服务 |
| WholeBody | 多部位位置/速度组合命令及命令镜像 |
| Chassis | 状态、心跳、缓存、速度、Motion/Force 模式、使能和复位 |
| Torso | 状态、心跳、缓存、完整位置、使能、复位、模式和取消动作 |
| Arm | 左右侧状态、心跳、缓存、完整位置、使能、模式、急停、复位和取消动作 |
| Hand | 状态、触觉、电子皮肤、完整位置、模式、触觉/e-skin 标定及零点标定查询/停止 |
| Sensors | IMU、超声、电子皮肤、Lidar和触觉皮肤置零 |
| Power | 电源板/电池状态、心跳、只读查询及明确确认的电源管理 |
| Video | 四路 AU 解码、JPEG 回调和视频诊断；使用随包视频运行库及插件 |
| Alignment | 视频、设备状态和 Master 状态的源时间戳匹配与诊断 |

公开能力取决于机器人是否安装并启用对应设备。运行时检查设备状态、SDK 错误和业务响应。

## Client 接口

每个 on_* 返回 `Result<Subscription>`；latest 接收最大年龄。各组使用规则与接口声明如下，具体调用流程见 [应用开发](%E5%BA%94%E7%94%A8%E5%BC%80%E5%8F%91.md).

### NorthSDK

创建实例后显式连接，通过访问器获取 Client。`version()` 返回版本，`connected()` 返回本地连接状态。

```cpp
class NorthSDK {
public:
    static Result<std::unique_ptr<NorthSDK>> Create(const SdkConfig& config);
    ~NorthSDK();
    NorthSDK(const NorthSDK&) = delete;
    NorthSDK& operator=(const NorthSDK&) = delete;

    Status connect();
    void close();
    bool connected() const noexcept;
    CallbackDiagnostics callback_diagnostics() const;
    TimeSyncDiagnostics time_sync_diagnostics() const;
    Result<std::int64_t> robot_time_ns() const;
    static const char* version() noexcept;

    ConfigClient config();
    MasterClient master();
    WholeBodyClient whole_body();
    ChassisClient chassis();
    TorsoClient torso();
    ArmClient arm(Side side);
    HandClient hand(Side side);
    SensorClient sensors();
    PowerClient power();
    VideoClient video();
    AlignmentClient alignment();

};
```

| 接口 | 参数 | 返回与作用 | 注意事项 |
| --- | --- | --- | --- |
| `Create(config)` | `config: SdkConfig` | C++ 返回 `Result<std::unique_ptr<NorthSDK>>`；创建但不连接实例 | 校验通道、超时和回调队列容量。Python 对应 `NorthSDK(config)`，失败抛 `NorthSDKError`。 |
| `connect()` | 无 | C++ `Status`；Python 成功返回 `None` | 建立通信并按配置准备对时。默认对时失败会返回错误但保留通信连接，应分别检查 `connected` 和对时诊断。 |
| `close()` | 无 | 无返回值 | 取消订阅、清空缓存并关闭连接；重连后需要重建用户订阅。析构和 Python `with` 退出也会关闭。 |
| `connected()` | 无 | `bool` | 返回本地通信会话是否已建立；设备在线情况通过心跳和状态流检查。 |
| `callback_diagnostics()` | 无 | `CallbackDiagnostics` | 返回累计丢弃/合并回调数量及最近解码错误。 |
| `time_sync_diagnostics()` | 无 | `TimeSyncDiagnostics` | 查询对时状态、偏差及错误；字段见[时间同步参数](#%E6%97%B6%E9%97%B4%E5%90%8C%E6%AD%A5%E5%8F%82%E6%95%B0)。 |
| `robot_time_ns()` | 无 | C++ `Result<int64_t>`；Python `int`，单位 ns | 读取与 North gPTP 同步的本机时钟；未连接、未启用或未就绪时返回错误。 |
| `version()` | 无 | 版本字符串 | 静态接口，不要求创建或连接 SDK。 |
| `config()`、`master()`、`whole_body()`、`chassis()`、`torso()`、`sensors()`、`power()`、`video()`、`alignment()` | 无 | 对应 Client | SDK 关闭后，Client 无法继续通信。 |
| `arm(side)`、`hand(side)` | `side: Side` | 绑定左右侧的 Client | 使用机器人自身视角的 Left/Right。非法值会在具体调用时返回 `kInvalidArgument`。 |

`SdkConfig.connect_endpoints` 和 `zenoh_config_path` 决定连接目标；单部位运动还必须在创建前配置 `command_channel`。完整默认值见本章 [SdkConfig 默认值](#sdkconfig-%E9%BB%98%E8%AE%A4%E5%80%BC)。

### Subscription

可移动、不可复制的订阅句柄。保存句柄以持续接收回调，析构或 `close()` 取消订阅。

```cpp
class Subscription {
public:
    Subscription();
    ~Subscription();
    Subscription(Subscription&&) noexcept;
    Subscription& operator=(Subscription&&) noexcept;
    Subscription(const Subscription&) = delete;
    Subscription& operator=(const Subscription&) = delete;

    void close();
    bool active() const noexcept;

};
```

| 接口 | 参数 | 返回与作用 | 注意事项 |
| --- | --- | --- | --- |
| `close()` | 无 | 取消当前订阅 | C++ 可显式调用或依赖析构；Python 可显式调用或使用 `with subscription:`。返回后不会再开始新的回调。 |
| `active()` | 无 | `bool` | 返回句柄是否尚未关闭。 |

### ConfigClient

```cpp
class ConfigClient {
public:
    Result<ConfigGetResponse> get(const std::string& plugin_id = {});
    Result<ConfigSetResponse> set(
        const std::string& plugin_id,
        const std::vector<ConfigFieldOperation>& operations);
};
```

`get()` 查询机器人开放的配置实例和字段；`set()` 持久化修改配置。实例和字段 ID 从 `get()` 返回值获取。

| 接口 | 参数与返回 |
| --- | --- |
| `get(plugin_id="")` | 空 ID 查询全部实例，非空 ID 查询指定实例；返回 `ConfigGetResponse`。 |
| `set(plugin_id, operations)` | 指定实例及字段操作列表；SET 携带值，RESET 不携带值。返回 `ConfigSetResponse`。 |

检查响应的 `result == ConfigResult::kOk`；失败时读取 `diagnostics`。修改前查看字段描述中的类型、范围和生效条件，修改后检查 `effective_value` 和 `pending_init`。写入超时后先调用 `get()` 确认实际结果。

类型和字段见[配置数据](#%E9%85%8D%E7%BD%AE%E6%95%B0%E6%8D%AE)。

### MasterClient

提供运行状态、健康、任务事件及系统服务。任务 ID 使用机器人已配置的名称。on_heartbeat 支持子系统名及 *。Master 服务检查 result，状态变更后继续观察状态流。

```cpp
class MasterClient {
public:
    Result<Subscription> on_status(std::function<void(const MasterStatus&)> callback,
                                   const SubscribeOptions& options = {});
    Result<Subscription> on_hardware_health(
        std::function<void(const SystemHardwareHealth&)> callback,
        const SubscribeOptions& options = {});
    Result<Subscription> on_task_start(std::function<void(const MasterEvent&)> callback,
                                       const SubscribeOptions& options = {});
    Result<Subscription> on_task_stop(std::function<void(const MasterEvent&)> callback,
                                      const SubscribeOptions& options = {});
    Result<Subscription> on_degradation(std::function<void(const MasterEvent&)> callback,
                                        const SubscribeOptions& options = {});
    Result<Subscription> on_error(std::function<void(const MasterEvent&)> callback,
                                  const SubscribeOptions& options = {});
    Result<Subscription> on_heartbeat(const std::string& subsystem,
                                      std::function<void(const Heartbeat&)> callback,
                                      const SubscribeOptions& options = {});
    Result<MasterStatus> latest_status(std::chrono::milliseconds max_age);

    Result<MasterResponse> set_mode(OperationMode mode);
    Result<MasterResponse> start_task(const std::string& task_id);
    Result<MasterResponse> stop_task(std::int32_t status = 0);
    Result<MasterResponse> reset();
    Result<MasterResponse> enter_ota();
    Result<MasterResponse> exit_ota();
    Result<MasterResponse> enter_estop();
    Result<MasterResponse> exit_estop();
    Result<ConfigSetResponse> set_health_requirement(const std::string& subsystem,
                                                     HealthRequirement requirement);
    Result<ConfigSetResponse> set_safety_guard_enabled(const std::string& guard_id, bool enabled);
    Result<BasicResponse> prepare_teleoperation();

};
```

| 接口 | 参数 | 返回数据 | 作用与约束 |
| --- | --- | --- | --- |
| `on_status(callback, options)` | 通用订阅参数 | `MasterStatus` | 订阅 Master 阶段、运行模式、任务 ID 和降级状态。 |
| `on_hardware_health(callback, options)` | 通用订阅参数 | `SystemHardwareHealth` | 订阅子系统健康、安全保护和主机资源汇总。 |
| `on_task_start(callback, options)` | 通用订阅参数 | `MasterEvent` | 订阅任务启动事件及接受、活动状态和原因。 |
| `on_task_stop(callback, options)` | 通用订阅参数 | `MasterEvent` | 订阅任务停止事件和结束状态。 |
| `on_degradation(callback, options)` | 通用订阅参数 | `MasterEvent` | 订阅系统降级事件。 |
| `on_error(callback, options)` | 通用订阅参数 | `MasterEvent` | 订阅 Master 错误事件及设备错误详情。 |
| `on_heartbeat(subsystem, callback, options)` | `subsystem: string`、通用订阅参数 | `Heartbeat` | 订阅指定子系统心跳，例如 `"lidar"`；传 `"*"` 订阅所有子系统。具体子系统名称不能为空且不能包含通配或路径特殊字符。 |
| `latest_status(max_age)` | 最大本机接收年龄 | `MasterStatus` | 主动读取新鲜 Master 缓存；无样本或过期返回 `kStaleState`。 |
| `set_mode(mode)` | `OperationMode`：Teleoperation、Inference 或 Automation | `MasterResponse` | 切换 Master 运行模式；允许切换的阶段由机器人状态决定，任务准备顺序见[应用开发](%E5%BA%94%E7%94%A8%E5%BC%80%E5%8F%91.md#%E4%BB%BB%E5%8A%A1%E5%87%86%E5%A4%87%E4%B8%8E%E7%BB%93%E6%9D%9F)。 |
| `start_task(task_id)` | 区分大小写的非空任务 ID，如 `inference`、`teleoperation`、`home`、`docking`，以交付配置为准 | `MasterResponse` | 请求启动任务；成功响应后仍需等待状态流进入 RUNNING。 |
| `stop_task(status=0)` | 32 位任务结束状态码，默认 0；其他值的含义由任务约定 | `MasterResponse` | 请求正常结束任务。`teleoperation` 会退出遥操作、执行回位并完成录制收尾，期间保持 RUNNING；成功响应不表示已经停稳。其他任务结束后也需观察状态与反馈。不能用作急停。 |
| `reset()` | 无 | `MasterResponse` | 请求 Master 恢复流程；实际允许阶段和结果由机器人状态机决定。 |
| `enter_ota()` / `exit_ota()` | 无 | `MasterResponse` | 进入或退出 OTA 阶段，会影响任务和设备操作。 |
| `enter_estop()` | 无 | `MasterResponse` | 请求系统急停；结合设备反馈确认结果。 |
| `exit_estop()` | 无 | `MasterResponse` | 启动异步恢复：复位并重新使能双臂、躯干，将双手恢复为位置模式。成功响应只表示已启动，需等待离开 ESTOP 并检查设备健康及反馈。调用前确认现场允许恢复，不直接重启旧控制循环。 |
| `set_health_requirement(subsystem, requirement)` | 子系统 ID；`HealthRequirement` 为 `OK`、`WARNING`、`OFF` 等要求 | `ConfigSetResponse` | 通过 Config 服务持久化 Master 健康准入规则，返回 `ConfigSetResponse`。 |
| `set_safety_guard_enabled(guard_id, enabled)` | 保护项 ID；`enabled` 表示启用或关闭 | `ConfigSetResponse` | 通过 Config 服务持久化安全保护设置，返回 `ConfigSetResponse`；仅应由获授权流程调用。 |
| `prepare_teleoperation()` | 无 | `BasicResponse` | 在 Master Teleoperation 模式下准备遥操作链路；准备完成后启动 `teleoperation` 任务。检查 `BasicResponse.success/message`。 |

Master 服务要求 SDK 已连接，使用 `master_timeout`（默认 15000 ms）。C++ 先检查 `Result<MasterResponse>`，再检查 `result == MasterResult::kOk`；Python 返回响应后检查 `MasterResult.OK`，SDK 错误抛 `NorthSDKError`。`prepare_teleoperation()` 检查 `BasicResponse.success/message`；健康要求和安全保护设置通过配置服务持久化，检查 `ConfigResult::kOk` 及 diagnostics。

`set_mode` 的 Teleoperation、Inference、Automation 对应同名 CommandChannel；Universal 只在发送时跳过模式匹配，仍要求新鲜 RUNNING。`before/after` 是响应快照，`message` 提供业务说明；继续通过 `on_status` 或 `latest_status` 确认实际模式及阶段。例程见[Master 模式服务](%E4%BE%8B%E7%A8%8B%E5%8F%82%E8%80%83.md#master-%E6%A8%A1%E5%BC%8F%E6%9C%8D%E5%8A%A1)。

常见 SDK 错误包括 `kNotConnected`、`kInvalidArgument`、`kTimeout`、`kTransport`、`kRemoteFailure` 和 `kOutcomeUnknown`。订阅与缓存通用规则见[通用参数与结果](#%E9%80%9A%E7%94%A8%E5%8F%82%E6%95%B0%E4%B8%8E%E7%BB%93%E6%9E%9C)。

组合多个部位的位置目标和底盘速度命令。

```cpp
class WholeBodyClient {
public:
    Status send(CommandChannel channel, const WholeBodyCommand& command);
    Result<Subscription> on_command(std::function<void(const WholeBodyCommand&)> callback,
                                    const SubscribeOptions& options = {});

```

| 接口 | 参数 | 返回与作用 | 约束 |
| --- | --- | --- | --- |
| `send(channel, command)` | `channel: CommandChannel`；`command: WholeBodyCommand` | C++ `Status`；Python 成功返回 `None` | `channel` 必须为 Teleoperation、Inference、Automation 或 Universal；`command` 至少填写一个部位。只更新已填写的 optional 字段。所有部位先通过本地校验；各部位分别执行，应用需分别检查反馈。 |
| `on_command(callback, options)` | 通用订阅参数 | `WholeBodyCommand` 回调 | 记录整机命令镜像；执行结果通过设备状态读取。 |

### ChassisClient

速度单位为 m/s、rad/s，输入必须为有限值。`set_mode` 显式切换整体 Motion/Force 模式；`mode` 从底盘心跳缓存读取当前模式。模式切换要求设备空闲且不处于 OTA 状态。

```cpp
class ChassisClient {
public:
    Result<Subscription> on_state(std::function<void(const ChassisState&)> callback,
                                  const SubscribeOptions& options = {});
    Result<Subscription> on_heartbeat(std::function<void(const Heartbeat&)> callback,
                                      const SubscribeOptions& options = {});
    Result<ChassisState> latest_state(std::chrono::milliseconds max_age);
    Status send_velocity(const ChassisVelocity& command);
    Result<ChassisModeResponse> set_mode(ChassisControlMode mode);
    Result<ChassisControlMode> mode(
        std::chrono::milliseconds max_age = std::chrono::milliseconds(500));
    Result<BasicResponse> enable(bool enabled = true);
    Result<BasicResponse> reset();

};
```

| 接口 | 参数 | 返回数据 | 作用与约束 |
| --- | --- | --- | --- |
| `on_state(callback, options)` | 通用订阅参数 | `ChassisState` | 订阅底盘速度、关节、电气和模式状态。 |
| `on_heartbeat(callback, options)` | 通用订阅参数 | `Heartbeat` | 订阅底盘生命周期、在线掩码、故障和频率信息。 |
| `latest_state(max_age)` | 最大本机接收年龄；Python 默认 1000 ms | `ChassisState` | 无样本或过期返回 `kStaleState`。 |
| `send_velocity(command)` | `ChassisVelocity` | `Status` / Python `None` | `vx`、`vy` 和 `extension_velocity` 单位 m/s，`vtheta` 单位 rad/s；所有值必须有限。经单部位 `command_channel` 和 Master 门禁发送。 |
| `set_mode(mode)` | `ChassisControlMode::kMotion` / `kForce` | `ChassisModeResponse` | 切换底盘整体运动/力控模式；返回 `success/message`、previous_mode 和 current_mode。模式切换后仍需确认设备已使能。 |
| `mode(max_age=500ms)` | 心跳最大本机接收年龄 | `ChassisControlMode` | 从新鲜底盘心跳读取，不发送服务请求。首次调用或心跳超过窗口时返回 `kStaleState`；Python 参数为 `max_age_ms`。 |
| `enable(enabled=true)` | `enabled: bool` | `BasicResponse` | `true` 请求使能，`false` 请求失能；检查业务响应和后续状态。 |
| `reset()` | 无 | `BasicResponse` | 请求底盘复位；复位是否改变使能/模式以设备状态反馈为准。 |

模式切换要求底盘空闲且不处于 OTA 冻结状态。心跳发布周期可能慢于默认 500 ms 窗口，应用可按时效要求增大 `max_age` 并始终处理过期结果。速度命令没有内置当前机型物理限幅，应用必须使用交付限制；正常停车应持续发送零速度，用新鲜 `ChassisState.velocity` 确认平移和转动速度在应用设定的静止容差内，并持续满足所需时间。

### TorsoClient

8 关节顺序为身体 J1–J5、颈部 J6–J8。发送完整 position。reset 后关节保持失能，重新运动前按应用流程使能。服务使用 torso_timeout。

```cpp
                                      const SubscribeOptions& options = {});

    Status send_joint_command(const JointCommand& command);
    Result<BasicResponse> enable(bool enabled = true);
```

| 接口 | 参数 | 返回数据 | 作用与约束 |
| --- | --- | --- | --- |
| `on_state(callback, options)` | 通用订阅参数 | `TorsoState` | 订阅 8 关节状态和电气数据。 |
| `on_heartbeat(callback, options)` | 通用订阅参数 | `Heartbeat` | 订阅躯干子系统健康与频率。 |

### ArmClient

arm(Side) 选择左右侧，每侧 7 关节。模式、使能、急停及复位是显式服务。模式切换后检查业务结果并观察设备状态。

```cpp
class ArmClient {
public:
    Side side() const noexcept;
    Result<Subscription> on_state(std::function<void(const ArmState&)> callback,
                                  const SubscribeOptions& options = {});
    Result<Subscription> on_heartbeat(std::function<void(const Heartbeat&)> callback,
                                      const SubscribeOptions& options = {});
    Result<ArmState> latest_state(std::chrono::milliseconds max_age);
    Status send_joint_positions(const std::array<float, 7>& positions);
    Status send_joint_command(const JointCommand& command);
    Result<BasicResponse> enable(bool enabled = true);
    Result<ModeResponse> set_mode(ControlMode mode);
    Result<BasicResponse> estop(const std::string& reason = {});
    Result<BasicResponse> reset();
    Result<BasicResponse> cancel_waypoints();

};
```

通过 `sdk.arm(Side)` 选择左右臂；`side()` 返回该 Client 绑定的侧别。

| 接口 | 参数 | 返回数据 | 作用与约束 |
| --- | --- | --- | --- |
| `side()` | 无 | `Side` | 返回创建 Client 时绑定的左右侧。 |
| `on_state(callback, options)` | 通用订阅参数；默认 DropOldest | `ArmState` 回调 | 持续接收绑定侧手臂状态，用于反馈、监视或记录；保存订阅句柄。 |
| `on_heartbeat(callback, options)` | 通用订阅参数 | `Heartbeat` | 订阅当前侧手臂的生命周期、关节在线掩码、故障和频率。 |
| `latest_state(max_age)` | C++ milliseconds 必填；Python `max_age_ms=1000`，非负 | `ArmState` | 按本机接收年龄读取缓存副本，自动建立状态接收；无数据或过期为 `kStaleState`。 |
| `send_joint_positions(positions)` | C++ `std::array<float, 7>`；Python 长度 7 的数值序列，单位 rad，值必须有限 | `Status` / Python `None` | 提交绑定侧完整关节位置目标，按机型固定顺序；不支持按名称重排、稀疏更新或速度/力矩控制。 |
| `send_joint_command(command)` | `JointCommand` | `Status` / Python `None` | 与 `send_joint_positions` 相同，只支持完整 7 项 position；name、velocity、torque 必须为空。 |

| `set_mode(mode)` | `ControlMode` | `ModeResponse` | 请求设备控制模式。当前位置命令应使用机器人交付流程要求的兼容位置模式；Master `OperationMode` 是另一层概念。 |
| `estop(reason="")` | 可选原因字符串 | `BasicResponse` | 请求当前侧设备急停。`reason` 用于记录急停原因。 |
| `reset()` | 无 | `BasicResponse` | 请求当前侧复位；复位后重新确认模式、使能、心跳和状态。 |
| `cancel_waypoints()` | 无 | `BasicResponse` | 请求取消当前侧 waypoint；继续观察反馈确认结果。 |

订阅和缓存规则见[通用参数与结果](#%E9%80%9A%E7%94%A8%E5%8F%82%E6%95%B0%E4%B8%8E%E7%BB%93%E6%9E%9C)。

位置发送要求：创建 SDK 时设置 `SdkConfig.command_channel`，SDK 已连接，Master 处于未超过 `master_status_max_age` 的 RUNNING 状态，Teleoperation/Inference/Automation 通道与 Master mode 匹配，设备已使能并进入兼容位置模式。SDK 校验长度、有限值和运动准入；目标准备要求见[运动控制](%E5%BA%94%E7%94%A8%E5%BC%80%E5%8F%91.md#%E8%BF%90%E5%8A%A8%E6%8E%A7%E5%88%B6)。

常见发送错误为 `kInvalidArgument`、`kNotConnected`、`kStaleState`、`kMotionNotAllowed`、`kTransport`。用新鲜 `ArmState.joints.position` 按应用容差和超时确认结果；反馈过期、Master 退出 RUNNING 或发生错误时停止发送。例程见[发送单臂关节目标](%E4%BE%8B%E7%A8%8B%E5%8F%82%E8%80%83.md#%E5%8F%91%E9%80%81%E5%8D%95%E8%87%82%E5%85%B3%E8%8A%82%E7%9B%AE%E6%A0%87)。

Arm 普通服务使用 `service_timeout`，默认 6000 ms。模式、使能、复位和急停的结果应结合后续状态判断。

### HandClient

每侧 22 关节。触觉 finger 为 0–4，从小指到拇指；图像类型为 kRaw/kDeform。二进制图像载荷在 Python 中为 bytes。触觉标定仅接受 enabled=true。提供零点标定状态查询和停止操作。服务检查 success/message。

先通过 `hand(Side)` 选择左手或右手，再用 `finger` 选择手指。两侧都使用 0=小指、1=无名指、2=中指、3=食指、4=拇指；例如 `finger=4` 选择所选手的拇指。

| 接口 | 参数 | 回调/返回数据 | 作用与约束 |
| --- | --- | --- | --- |

### SensorClient

提供 IMU、超声、电子皮肤与 Lidar 数据。Lidar 自动解压 Zstd 数据并返回点云，无需额外安装解压库。根据 `kind` 读取 `laser_shots[].points` 或 `sub_areas[].points`，点包含以米为单位的坐标和反射强度。不支持的压缩格式返回 `kNotSupported`。

```cpp
class SensorClient {
public:
    Result<Subscription> on_imu(std::function<void(const ImuSamples&)> callback,
                                const SubscribeOptions& options = {});
    Result<Subscription> on_ultrasonic(std::function<void(const UltrasonicSamples&)> callback,
                                       const SubscribeOptions& options = {});
    Result<Subscription> on_tactile_skin(std::function<void(const TactileSkinSamples&)> callback,
                                         const SubscribeOptions& options = {});
    Result<Subscription> on_lidar(LidarSource source,
                                  std::function<void(const LidarFrame&)> callback,
                                  const SubscribeOptions& options = {});
    Result<ImuSamples> latest_imu(std::chrono::milliseconds max_age);
    Result<BasicResponse> zero_tactile_skin(bool enabled = true);

};
```

| 接口 | 参数 | 回调/返回数据 | 作用与约束 |
| --- | --- | --- | --- |
| `on_imu(callback, options)` | 通用订阅参数 | `ImuSamples` | 订阅一帧中的一个或多个 IMU；角速度 rad/s、线加速度 m/s²，四元数字段为 w/x/y/z。 |
| `on_ultrasonic(callback, options)` | 通用订阅参数 | `UltrasonicSamples` | 订阅超声距离和状态；使用前同时检查 `valid` 与 `status`。距离字段单位 mm。 |
| `on_tactile_skin(callback, options)` | 通用订阅参数 | `TactileSkinSamples` | 订阅机身电子皮肤点阵力，力单位 N；检查每块 skin 的 `valid`。 |
| `on_lidar(source, callback, options)` | `source: LidarSource` | `LidarFrame` | 选择底盘前、胸部前或胸部后 Lidar。非法来源返回 `kInvalidArgument`；Zstd 由 SDK 自动解压并返回点云。 |
| `latest_imu(max_age)` | 最大本机接收年龄；Python 默认 1000 ms | `ImuSamples` | 读取新鲜 IMU 缓存；无数据或过期返回 `kStaleState`。 |
| `zero_tactile_skin(enabled=true)` | `enabled: bool` | `BasicResponse` | `true` 将当前力设为 0 N 基线，`false` 恢复拟合力。会改变后续读数解释，需检查 `success/message`。 |

传感器订阅的可用性取决于机器人设备配置。订阅建立成功但没有回调时，应检查对应数据源。

### PowerClient

读取电源或电池时检查样本新鲜度及 reading.quality；仅 kValid 且 value 存在时使用读数，零值也可能有效。channel_command 使用具体节点。改变供电的操作需 confirm_power_change；release_estop 和 shutdown 还要求非空 reason。

```cpp
class PowerClient {
public:
    Result<Subscription> on_chest_state(std::function<void(const PowerBoardState&)> callback,
                                        const SubscribeOptions& options = {});
    Result<Subscription> on_chassis_state(std::function<void(const PowerBoardState&)> callback,
                                          const SubscribeOptions& options = {});
    Result<Subscription> on_battery(std::function<void(const BatterySystemState&)> callback,
                                    const SubscribeOptions& options = {});
    Result<Subscription> on_heartbeat(std::function<void(const Heartbeat&)> callback,
                                      const SubscribeOptions& options = {});
    Result<BatterySystemState> latest_battery(std::chrono::milliseconds max_age);
    Result<PowerCommandResponse> channel_command(const PowerChannelCommand& command);
    Result<PowerCommandResponse> estop(PowerNode node, const std::string& reason);
    Result<PowerCommandResponse> release_estop(PowerNode node, const std::string& reason,
                                               bool confirm_power_change);
    Result<PowerCommandResponse> shutdown(PowerNode node, const std::string& reason,
                                          bool confirm_power_change);

};
```

Power 状态流即使数据不可用也可能持续发布。读取数值时必须同时检查样本新鲜度、`PowerDataQuality` 和 optional `value`；数值 0 可能是有效测量。

| 接口 | 参数 | 回调/返回数据 | 作用与约束 |
| --- | --- | --- | --- |
| `on_chest_state(callback, options)` | 通用订阅参数 | `PowerBoardState` | 订阅胸部电源板读数、输出和切换状态。 |
| `on_chassis_state(callback, options)` | 通用订阅参数 | `PowerBoardState` | 订阅底盘电源板状态。 |
| `on_battery(callback, options)` | 通用订阅参数 | `BatterySystemState` | 订阅电池包电压、电流、SOC、温度、限值和故障码。 |
| `on_heartbeat(callback, options)` | 通用订阅参数 | `Heartbeat` | 订阅电源子系统生命周期和故障信息。 |
| `latest_battery(max_age)` | 最大本机接收年龄；Python 默认 1000 ms | `BatterySystemState` | 读取新鲜电池缓存；还需逐读数检查 quality/value。 |
| `channel_command(command)` | `PowerChannelCommand` | `PowerCommandResponse` | 指定具体 node（不能使用 `kAll`）、opcode 及操作字段。只读操作无需确认；会改变供电状态的 opcode 必须设置 `confirm_power_change=true`。 |
| `estop(node, reason)` | `PowerNode` 和原因字符串 | `PowerCommandResponse` | 请求指定电源节点急停。应提供可追踪原因，并检查 `success`、`error_code` 和状态反馈。 |
| `release_estop(node, reason, confirm_power_change=false)` | 节点、非空原因、显式确认 | `PowerCommandResponse` | 解除急停会改变供电状态；必须传 `true`，默认 `false` 用于防止误调用。 |
| `shutdown(node, reason, confirm_power_change=false)` | 节点、非空原因、显式确认 | `PowerCommandResponse` | 关闭指定节点；必须显式确认，可能导致连接和状态流立即中断。 |

`PowerChannelCommand` 中 `channel_id/action` 用于单通道操作，`set_mask/clear_mask` 用于掩码操作，`heartbeat_period_ms` 用于对应心跳周期命令；具体组合由 `PowerOpCode` 决定。所有 Power 服务使用 `service_timeout`；超时后先通过剩余状态或现场检查确认结果。

### VideoClient

```cpp
class VideoClient {

        VideoSource source,

```

订阅相机 JPEG 图像并查询接收诊断。安装包包含视频运行库，使用前完成[视频环境准备](%E5%BA%94%E7%94%A8%E5%BC%80%E5%8F%91.md#%E8%A7%86%E9%A2%91%E7%8E%AF%E5%A2%83%E5%87%86%E5%A4%87)。

| 方法 | 参数 | 返回 | 说明 |
| --- | --- | --- | --- |
| `on_jpeg(source, callback, options)` | source：头部左右目 H.265 或左右腕 H.264；callback：接收 JpegFrame；options：VideoOptions | `Result<Subscription>` | 保存订阅句柄。同一路相机只允许一个活动订阅，也不能与对齐会话重复占用。 |
| `diagnostics(source)` | 与订阅相同的 VideoSource | `Result<VideoDiagnostics>` | 查询接收/输出数量、丢弃、重置和最近错误。 |

`VideoOptions` 默认使用 NVDEC、JPEG 质量 85、输出 1280×960；可设置 `decoder_backend`、`jpeg_quality`、`output_width/output_height` 及输入队列容量。宽高同时为 0 时保留源尺寸。软件解码需显式选择 `kSoftware`，不会自动回退；多路或高分辨率输入下性能较差。

回调中的 `JpegFrame` 包含相机、header、尺寸和完整 JPEG `data`。C++ 引用仅在回调内有效，异步处理需复制；Python data 为 `bytes`。回调应简短，慢消费者可能跳帧。

非法参数返回 `kInvalidArgument`，相机已占用返回 `kUnavailable`；视频环境错误见返回信息和 `diagnostics()`。


| 方法 | 参数 | 返回 | 说明 |
| --- | --- | --- | --- |
| `on_frame(options, callback, callback_options)` | options：AlignmentOptions；callback：接收 AlignedFrame | `Result<Subscription>` | 保存订阅句柄。`callback_options` 当前不影响输出行为；回调应保持简短。 |
| `diagnostics(subscription)` | 本 SDK 创建且仍活动的对齐订阅 | `Result<AlignmentDiagnostics>` | 查询完整/不完整帧、时间戳异常及各来源匹配统计。 |

| AlignmentOptions | 说明 |
| --- | --- |
| `baseline` / `sources` | 基准来源与附加来源。默认以头部左目为基准并自动匹配右目；其他基准只匹配显式 sources。来源不能重复。 |
| `max_skew` / 逐源 `max_skew` | 匹配容差，逐源设置优先；0 要求时间完全相同。未设置时使用下述默认值。 |

默认容差：臂/躯干/底盘/手关节/IMU 为 7.5 ms，电子皮肤为 15 ms，视频为 25 ms，手指触觉为 50 ms，Master 为 150 ms。Python 容差和等待时间属性分别为 `max_skew_ns`、`wait_timeout_ms`；`None` 使用默认容差。

`AlignedFrame` 包含 `timestamp_ns`、`baseline_sample`、按 sources 顺序排列的 `samples` 和 `complete`。状态为 Matched、Missing 或 OutOfTolerance。结果读取规则见[视频与对齐数据](#%E8%A7%86%E9%A2%91%E4%B8%8E%E5%AF%B9%E9%BD%90%E6%95%B0%E6%8D%AE)。`offset_ns` 是候选时间减基准时间。

头部 JPEG 使用 RK SEI 源时间，其他设备通常使用 Header 时间；跨源对齐前确认时间域一致。调用示例见[例程参考](%E4%BE%8B%E7%A8%8B%E5%8F%82%E8%80%83.md)。

## 时间同步参数

`SdkConfig.time_sync` 使用以下字段。软件模式会调整开发机系统时间，主机准备见[时间同步](%E5%BA%94%E7%94%A8%E5%BC%80%E5%8F%91.md#%E6%97%B6%E9%97%B4%E5%90%8C%E6%AD%A5)。

| TimeSyncOptions 字段 | 默认值与约束 |
| --- | --- |
| `enabled` | `true`；关闭后跳过对时。 |
| `mode` | `TimeSyncMode::kSoftware`；可选 `kHardware`。Python 为 `TimeSyncMode.SOFTWARE/HARDWARE`。 |
| `interface` | 空字符串；按机器人端点路由选择物理有线网卡，无法唯一确定时报错。 |
| `timeout` / Python `timeout_ms` | 60000 ms，必须大于 0；初次对时准备的等待期限。 |
| `failure_policy` | `TimeSyncFailurePolicy::kKeepConnected`；初次对时失败返回错误但保留通信。`kFailConnection` 则关闭通信。Python 为 `KEEP_CONNECTED/FAIL_CONNECTION`。 |
| `software_offset_threshold_ns` | 1000000 ns；允许 1–1000000000 ns，仅用于软件模式就绪判断。硬件模式门槛固定为 50 ns。 |

`TimeSyncDiagnostics.state` 为 `Disabled`、`Preparing`、`Ready`、`Failed` 或 `Lost`（C++ 枚举有 `k` 前缀，Python 为大写下划线）。连续 10 个新观测的偏差绝对值小于门槛才就绪；运行中失锁需重新检查。

| 诊断字段 | 说明 |
| --- | --- |
| `error` | SDK 错误码和消息。 |
| `mode/interface/phc_device` | 所选模式、网卡和硬件时钟设备；软件模式没有 PHC 设备。 |
| `clock_source/system_time_owned` | 取时来源为 `CLOCK_REALTIME` 或 `PHC`；是否由本组件管理系统授时。 |
| `offset_ns/offset_threshold_ns` | 观测偏差及就绪门槛，单位 ns；门槛用于判断对时是否就绪。 |
| `stable_samples/required_samples` | 连续合格观测数及要求数量。 |
| `sample_age` / Python `sample_age_ms` | 诊断样本年龄；超过 1 秒不再视为就绪。 |
